# ParaBank - Plano de Testes
  Sistema de testes para o ParaBank, uma aplicação bancária de demonstração que simula operações financeiras como consultas, transferências e empréstimos.

## Sobre o Projeto
   O ParaBank é um sistema bancário online de demonstração utilizado para fins educacionais e de validação de testes. Este repositório contém o plano de testes desenvolvido para validar as principais funcionalidades do sistema.
   
## Objetivo dos testes
   Validar o software de acordo com os critérios de aceite e escopos definidos, assegurando a integridade das funcionalidades essenciais. O processo visa identificar, documentar e reportar inconsistências (bugs) para garantir uma experiência de uso estável e confiável.

# Premissas e Riscos
 ## Premissas
   - O sistema estará disponível durante todo o período de testes
   - As funcionalidades em escopo estarão implementadas
   - Os usuários de teste terão acesso ao sistema
   - O ambiente de testes será estável

 ## Riscos
   - Instabilidade do sistema durante os testes
   - Falhas inesperadas nas funcionalidades
   - Atrasos no desenvolvimento que impactem os testes
   - Tempo insuficiente para execução completa dos testes
