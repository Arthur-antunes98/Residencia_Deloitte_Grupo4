# ParaBank - Plano de Testes
  Sistema de testes para o ParaBank, uma aplicação bancária de demonstração que simula operações financeiras como consultas, transferências e empréstimos.

## Sobre o Projeto
   O ParaBank é um sistema bancário online de demonstração utilizado para fins educacionais e de validação de testes. Este repositório contém o plano de testes desenvolvido para validar as principais funcionalidades do sistema.
   
## Objetivo
   Garantir que as funcionalidades principais do sistema estejam funcionando corretamente, de acordo com os critérios definidos.

## Funcionalidades Testadas
   - Accounts Overview
   - Open New Account
   - Transfer Funds
   - Request Loan

## Fora do Escopo
   - Integração com sistemas bancários reais
   - Processamento financeiro real
   - Testes de segurança avançada
   - Testes de performance

## Estratégia de Testes
   Os teste são realizados manualmente, incluindo:
   - Testes funcionais
   - Testes de interface
   - Testes de API

## Ferramentas Utilizadas
   - Insomnia
   - Google Docs
   - Trello
